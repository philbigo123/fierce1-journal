Google Drive Setup Guide

One-time 15-minute setup · Your data saves to Google Drive forever after

What this does: After setup, every trade, journal entry, and session level you save is automatically written to a file called fierce1_journal.json inside a FIERCE1 Systems folder in your Google Drive. Open the journal on any device, sign in, and your data is right there.
⚠ Important — Host the file on Google Drive: Google's APIs block connections from local files (file://). The easiest fix is to upload this HTML file to Google Drive, then open it from there. Go to drive.google.com → upload the file → right-click → Open with → Google Chrome (or just double-click). This makes Drive the host and everything works instantly.
Step 1 — Create a Google Cloud Project
1

Open Google Cloud Console

Go to console.cloud.google.com and sign in with your Google account.

At the top, click the project dropdown → New Project. Name it FIERCE1 Journal and click Create. Wait ~30 seconds.

Step 2 — Enable the Google Drive API
2

Enable Drive API

In the left sidebar go to APIs & Services → Library. Search for Google Drive API. Click it, then click Enable.

Wait for it to enable (about 10 seconds) then proceed to Step 3.

Step 3 — Create OAuth Credentials
3

Create OAuth 2.0 Client ID

Go to APIs & Services → Credentials → Create Credentials → OAuth client ID.

If prompted to configure a consent screen first: choose External, fill in App name (FIERCE1 Journal), your email, click Save. Then return to Credentials.

Application type: Web application. Name: FIERCE1 Journal.

Under Authorized JavaScript origins add ALL of these (one per line):

https://drive.google.com  ← most important

http://localhost

http://localhost:8080

Click Create. A popup shows your Client ID — copy it.

Step 4 — Add Yourself as a Test User
4

Add Test User (required until app is published)

Go to APIs & Services → OAuth consent screen. Scroll to Test users → click Add Users. Enter your own Gmail address. Click Save.

⚠ Without this step Google will block the sign-in with an "Access blocked" error.

Step 5 — Paste Your Client ID Here

Copy the Client ID from the popup in Step 3 (it ends in .apps.googleusercontent.com) and paste it below. Click Save — you only do this once.

Step 6 — Connect Google Drive

Once your Client ID is saved above, click the button below (or the Connect Drive button in the top-right of the header). Google will open a login popup — sign in and grant permission. That's it.

Recommended workflow:
1. Upload this HTML file to your Google Drive
2. Open it from Google Drive (right-click → Open with → Chrome)
3. Paste your Client ID in Step 5 below and click Save & Activate
4. Click Connect Drive — Google login popup appears — sign in — done
5. Bookmark the Google Drive URL — use that bookmark on every device

Your data file fierce1_journal.json will appear in a FIERCE1 Systems folder in your Drive. It syncs automatically every time you save a trade, journal entry, or session levels.
